# 제품 요구사항

상태: 검토용 초안 / 2026-11-27. 구현 승인 전이다. 초기 사용자 범위는 단일 교육기관의 학생과 선생님이며, 기관 다중화는 향후 별도 설계한다.

## 목적과 사용자

학생은 담당 선생님과 질문·답변을 주고받고 AI에게 학습 설명과 계획을 요청한다. 선생님은 담당 학생의 일반 채팅만 사용한다. AI 대화·기억·취약점은 학생 개인 정보로 취급하며 선생님에게 자동 공개하지 않는다. 담당 관계는 권한 있는 운영 절차 또는 학생의 초대 승인으로 확정하고 자기 주장만으로 생성하지 않는다.

## 제품 정책

- 일반 채팅은 AI 분석·기억 추출 대상이 아니다. 향후 활용에는 별도 처리 근거·권한·철회·삭제 정책이 필요하다.
- AI는 학습 지원이며 추론한 취약점을 확정 사실이나 성적처럼 표현하지 않는다. 답을 바로 제시하기보다 힌트·설명·확인 질문을 지원한다.
- 세션 종료는 새 질문 차단과 요약/추출 예약이다. 진행 중 답변은 완료·저장할 수 있다. 삭제는 모든 신규·진행 작업의 게시를 차단한다.
- 대화 원본과 AI 기억은 별도 데이터다. 삭제의 파생 데이터 범위는 MEMORY_POLICY에 따른다.

## 초기 비기능 목표

개발 측정 목표(보장 수치 아님): 동시 사용자 50명, 일반 메시지 커밋→수신 p95 500ms 이내, 일반 REST p95 500ms 이내, AI 등록 p95 1s 이내. AI 생성은 초기 전체 동시성 1로 시작하고 첫 토큰/완료 시간과 queue age를 기록한다. 목표는 하드웨어 평가 후 확정한다. 메시지 유실·학생 범위 누출·취소 후 게시·중복 최종 답변은 허용하지 않는다.

## 초기 범위 제외 및 확인 사항

그룹 채팅, 파일 첨부 채팅, 음성·영상, 외부 SaaS LLM, 다중 기관, 운영용 관리 콘솔은 초기 구현 범위 밖이다. 자료 업로드는 RAG 관리 경로로 제한한다.
운영 전에는 대상 연령·기관 권한 부여 주체·개인정보 처리 근거·원본 보관 기간·배포 규모를 확정한다. 이 정보가 없어도 로컬 가상 데이터 기반 환경 구축과 테스트는 진행할 수 있다.
